🔍 Google Search Console Setup Checklist

For toolboxsuite.in — complete these steps to get indexed on Google. Estimated total time: ~45 minutes.

⚠️ Why this is urgent A search for site:toolboxsuite.in returns zero results — Google has not indexed your website yet. Until you complete this checklist, no one can find your tools through Google search, no matter how good they are.

1
Set up Google Search Console
⏱ 10 min
Go to Google Search Console Do first
Open search.google.com/search-console and sign in with your Google account.
Add a new property
Click + Add property → choose Domain type → enter toolboxsuite.in (without https://). Domain type covers all subdomains automatically.
Verify ownership via DNS Required
Copy the TXT record Google provides (e.g. google-site-verification=abc123...). Log into your domain registrar (GoDaddy / Namecheap / Hostinger etc.) → DNS settings → Add a new TXT record for @ with that value. DNS propagation takes 5–30 minutes.
Click "Verify" in Search Console
After adding the DNS record, return to Search Console and click Verify. If it fails, wait 15 more minutes and try again.
2
Upload sitemap.xml and robots.txt
⏱ 5 min
Upload sitemap.xml to your server root Critical
The sitemap.xml file in this download must be accessible at https://toolboxsuite.in/sitemap.xml. Upload it to your web host's root public directory (usually public_html/ or www/).
Upload robots.txt to your server root
Upload robots.txt to the same root directory. It must be accessible at https://toolboxsuite.in/robots.txt. Test it by opening that URL in your browser after upload.
Submit sitemap in Search Console
In Search Console, go to Sitemaps (left sidebar) → enter sitemap.xml → click Submit. Status should change to "Success" within a few minutes.
3
Deploy the new multi-page site structure
⏱ 15 min
Upload all HTML files to server root Critical
Upload all .html files from this download to your web root. Each tool now has its own URL: /remove-background, /pdf-to-word, /pdf-merger, etc. This is the #1 change for SEO.
Upload style.css and main.js
Upload style.css and main.js to the root. All pages reference these as /style.css and /main.js.
Test all 9 tool pages in browser
Visit each URL and confirm the page loads correctly: /remove-background, /pdf-to-word, /word-to-pdf, /excel-to-pdf, /pdf-to-excel, /image-compressor, /pdf-merger, /image-resizer, /jpg-to-png.
Create an og-image.png for social sharing Recommended
Create a 1200×630px image with your logo, site name, and tagline "Free Online Tools — 100% Private". Upload it as /og-image.png. This appears when someone shares your site on WhatsApp, LinkedIn, Twitter.
Create a favicon.ico
Export your logo as a 32×32 .ico file and upload as /favicon.ico. Use favicon.io to convert for free. This appears in browser tabs and search results.
4
Request indexing for all pages
⏱ 10 min
Use URL Inspection to request indexing for homepage
In Search Console → URL Inspection → paste https://toolboxsuite.in/ → click Request Indexing. Google will prioritise crawling it.
Request indexing for each tool page
Repeat URL Inspection + Request Indexing for all 9 tool URLs. You can do max 10 requests per day, so do homepage + all 9 tools today: /remove-background, /pdf-to-word, /word-to-pdf, /excel-to-pdf, /pdf-to-excel, /image-compressor, /pdf-merger, /image-resizer, /jpg-to-png.
Wait 3–7 days, then verify indexing
After a week, search site:toolboxsuite.in on Google. You should see all 10 pages listed. If pages are missing, check Search Console's Coverage report for errors.
